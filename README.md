# Spot on Hold, rediseño

Landing page de una sola página para Spot on Hold (Mayagüez, Puerto Rico): mensajes en espera, directorios e IVR, cuadros telefónicos virtuales, In Store, grabaciones especiales y voiceovers.

Incluye el Portal del cliente (portal.html) con preguntas frecuentes, diagnóstico de equipos, apps y formulario de apoyo técnico. Incluye los 23 audios de ejemplo del sitio original, reproductor con visualizador en vivo y formulario de cotización que abre WhatsApp o correo con la solicitud lista.
